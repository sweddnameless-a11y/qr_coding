# MIREA QR — личная отметка из мобильного веб-приложения

Это PWA с камерой, входом через MIREA SSO, поддержкой дополнительного кода (2FA) и автоматической отправкой **одного запроса для текущего аккаунта** после считывания QR-кода.

## Что реализовано

- Мобильный интерфейс для iPhone, Android и компьютера.
- Вход через `MireaAuth.login()` и поддержка `MireaAuth.complete_2fa()`.
- Серверная сессия хранится по случайному HttpOnly-cookie. Сами данные сессии шифруются `pymirea` перед записью в SQLite; пароль в базу не записывается.
- После успешного входа камера считывает QR. Если QR отсканирован до входа, он временно остаётся в памяти страницы и отправляется после успешной авторизации.
- Запрос личной отметки выполняется через `MireaAPI.mark_attendance(qr_data)` и отображает ответ сервера, а не выдуманный результат.
- На стороне браузера и сервера проверяются HTTPS, разрешённый домен и единственный непустой параметр `token`.
- QR-сканер не загружает сторонний JavaScript. Браузер отправляет JPEG-кадр только на этот же сервер, где OpenCV распознаёт QR. Кадры не сохраняются и не логируются.
- Сервис-воркер кэширует только оболочку приложения. Ответы `/api/`, cookies, QR-запросы и состояние входа не кэшируются.

## Важно перед входом

Это **неофициальное** стороннее приложение. Вводи учётные данные только после того, как сам разместил код на хостинге, которому доверяешь, и проверил адрес сайта. Пароль передаётся по HTTPS с твоего браузера на твой сервер; сервер передаёт его в MIREA SSO для входа, не сохраняет и не пишет в логи. Сессия доступа хранится зашифрованной на сервере. Не используй чей-то чужой экземпляр сайта и не публикуй `.env`, базу или ключ шифрования.

Приложение отправляет запрос только для текущего авторизованного аккаунта. Оно не отмечает другие аккаунты. Валидная ссылка QR сама по себе не гарантирует успех: окончательный результат определяет сервер МИРЭА. Если интерфейс/API МИРЭА изменится, совместимость `pymirea` может потребовать обновления.

## 1. Локальный запуск на Windows

Понадобится Python 3.11 или новее.

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Сгенерируй ключ шифрования:

```powershell
py -c "import secrets,base64; print(base64.b64encode(secrets.token_bytes(32)).decode())"
```

Открой `.env` и замени `REPLACE_WITH_BASE64_32_BYTE_KEY` на полученную строку. Не отправляй её никому и не добавляй `.env` в Git. Запусти сервер:

```powershell
uvicorn server:app --host 127.0.0.1 --port 8000
```

На компьютере открой `http://127.0.0.1:8000`. Локальный HTTP разрешён только на `localhost`/`127.0.0.1` для разработки. Для камеры на физическом iPhone нужен HTTPS-адрес.

## 2. Размещение для iPhone

GitHub Pages не подойдёт: теперь нужен Python backend для входа, шифрования сессии и обработки QR.

Размести весь проект на сервере, которому доверяешь, с HTTPS и Python 3.11+. Настрой на хостинге переменные окружения:

- `APP_ORIGIN` — точный HTTPS-адрес приложения без завершающего `/`, например `https://qr.example.com`.
- `MIREA_SESSION_KEYS` — стабильный Base64-ключ, созданный командой выше. Сохрани его в менеджере секретов хостинга; при смене ключа сохранённые сессии станут нечитаемыми.
- `DATA_DIR` — путь к **постоянному диску** хостинга, где может храниться зашифрованная SQLite-база. Если файловая система хостинга временная, после перезапуска вход может сбрасываться.

Команда запуска:

```bash
uvicorn server:app --host 0.0.0.0 --port ${PORT:-8000} --proxy-headers
```

Если хостинг не поддерживает постоянное хранилище, сессия приложения может исчезнуть после перезапуска; это не означает, что пароль хранится или восстанавливается. Не публикуй папку `data/` и не раздавай файлы проекта как статический каталог целиком.

После публикации открой свой HTTPS-адрес в Safari на iPhone → «Поделиться» → «На экран Домой» → «Добавить». На Android — Chrome → меню → «Установить приложение».

## 3. Использование

1. Открой свой HTTPS-адрес и проверь домен.
2. Войди через форму МИРЭА. Если потребуется 2FA, введи код подтверждения.
3. Нажми «Включить камеру» и разреши доступ. Можно также выбрать изображение QR или вставить ссылку.
4. После успешного распознавания приложение сразу отправит запрос для твоего аккаунта и покажет ответ сервера. Не сканируй один и тот же QR много раз подряд.
5. Если вход истёк — войди заново.

## Файлы

- `server.py` — API, вход/2FA, шифрованное хранилище, обработка QR-кадров и личная отметка.
- `index.html`, `styles.css`, `app.js` — мобильный PWA-интерфейс.
- `manifest.webmanifest`, `sw.js`, иконки — установка на главный экран и кэширование оболочки.
- `requirements.txt` — зависимости.

## Проверки и ограничения

В исходниках были доступны фрагменты реализации MireaAuth/MireaAPI, а не весь исходный проект с его внутренними зависимостями. Поэтому интеграция использует API `pymirea` (`MireaAuth`, `MireaAPI`), заявленные в документации пакета; в этом окружении реальные данные МИРЭА и живой вход проверить невозможно. Перед реальным использованием проверь вход и обработку результата на своём аккаунте, не публикуя пароль или сессионные cookies.
